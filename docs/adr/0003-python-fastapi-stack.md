# Python, FastAPI, and SQLite for Backend Stack

To satisfy the recruitment requirements of high evaluator developer experience, zero setup friction, and rapid local demonstrability, we selected Python with FastAPI, SQLAlchemy, SQLite, and Pillow. FastAPI delivers native, interactive OpenAPI/Swagger documentation (`/docs`) with zero configuration and built-in Pydantic v2 request validation. SQLite avoids requiring external running database engines or container dependencies for evaluators, while Pillow provides efficient in-memory EXIF metadata stripping for file uploads.
