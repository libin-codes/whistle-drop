This directory contains visual media, UI screenshots, and video walkthroughs referenced in `README.md`.

## Recommended Capture Guidelines

* **Theme / Styling**: Match the dark modern theme (`#090d16` background, `#111827` cards, emerald/sky accents).
* **Screenshots Resolution**: 1920x1080 (or retina 2x scaled at 16:9 / standard desktop viewport `1280x720`).
* **Format**: `.png` (lossless, compressed via pngquant/optipng) or `.webp`.
* **Demo Video**: MP4 format (H.264 / AAC), resolution 1080p, 30fps, target duration under 60 seconds (or lightweight animated GIF / WebM).
